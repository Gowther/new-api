## 日志导出约定

双前端的用量日志页面新增“导出 CSV”。打开对话框时固定已应用的查询条件，导出符合条件的全部记录，不受当前分页限制。

- 管理员接口：`GET /api/log/export`；用户接口：`GET /api/log/self/export`。
- 普通用户只能导出本人的记录；服务端移除管理员调试信息、审计细节和渠道信息。管理员 CSV 额外包含用户和渠道列。
- 时间范围最多 365 天，请求最长 5 分钟；同一用户同时只能运行一个导出。启用 Redis 时，导出锁跨节点生效；无 Redis 时使用进程内锁。
- 后端使用数据库游标逐行输出 NDJSON；末行返回成功标记与总数。前端验证完整结束及数量一致后才生成 CSV，取消或中断不会生成成功文件。
- CSV 包含 UTF-8 BOM，处理引号、换行和电子表格公式前缀。浏览器会暂存响应与 CSV 内容，大规模结果应缩小查询时间范围。
- 未指定时间范围的直接 API 请求默认导出最近 365 天。缺少结束时间时取当前时间；缺少开始时间时取结束时间前 365 天。
